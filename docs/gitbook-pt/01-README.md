## O que é o Optimizer?

Optimizer é um **Meta-Hook Engine para Uniswap V4** que captura MEV (Miner Extractable Value) que normalmente seria roubado por robôs de arbitragem, e devolve aos provedores de liquidez.

### O Problema

No Uniswap, quando uma grande troca acontece:
1. O preço se move
2. Robôs de arbitragem detectam a diferença de preço
3. Executam operações para capturar a diferença
4. **LPs do varejo perdem dinheiro**

### A Solução

O Meta-Hook de 3 Camadas do Optimizer:
1. **Identity-Fi** — Holders de NFT pagam 0% de taxas
2. **Elasticidade** — Ajuste automático de oferta
3. **Internalização de MEV** — Captura lucros de arbitragem internamente
